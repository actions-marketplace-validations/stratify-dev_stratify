### Task 1: Strict precision-tool input validation (gap 1)

**Files:** `scripts/precision.py`, `scripts/test_precision.py`.

**Requirement:** every malformed input exits 2 with a concise `precision:` error, never a traceback. A clone, checkout, or scan failure still exits 1. Validate all fields before anything uses them:

- **Labels.** `rule`, `file`, `match`, `label`, and `note` must each be a `str` that is non-empty after stripping whitespace. `line` must be an `int` that is not a `bool` and is at least 1. `rule` must be in `RULES`. `label` must be `tp` or `fp`. A label that is not an object is an error, and so is a `labels` value that is not a list.
- **Labels document.** The document itself must be an object. `complete_rules` must be a list, and each entry must be a `str` that names a known rule. Report duplicates in `complete_rules` too.
- **Repo manifest** (`repos.json`). It must be a list. Each entry must be an object with non-empty `str` values for `name`, `url`, and `commit`. Names must be unique, and each name must be safe as a single path component: no `/`, no `..`, no leading `.`. Every entry's labels file must exist. Report all manifest errors before cloning anything.
- **Applicability** (`applicability.json`). The document must be an object with a `not_applicable` list. Every entry must be an object whose `rule`, `language`, `reason`, and `reviewed_by` are non-empty strings. Keep the existing known-rule, known-language, and duplicate checks.
- **Collection order.** Collect manifest, applicability, and every repo's label-schema errors before any clone. If any exist, print all of them and exit 2. Clone and scan only on a clean schema pass.

**Tests:** add a unit test for each case in the gaps file:
- wrong field types, including an integer `match`, which is the reproduced `TypeError`
- empty `match` and empty `note`
- `line` as `true`, `0`, `-1`, or `"3"`
- a non-string entry in `complete_rules`
- a manifest that is not a list
- manifest entries that are not objects or lack fields, plus duplicate names and unsafe names
- malformed applicability values

Add one end-to-end subprocess case per class to confirm exit 2 with no `Traceback` in stderr: a malformed label, a malformed manifest, and a malformed applicability file. Use TDD and capture RED first.

Commit with subject `fix(scripts): validate every corpus input before use`.
